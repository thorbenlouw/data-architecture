Regulations and standards state requirements in general terms, such as "restrict access to authorised users" or "test recovery regularly". Compliance controls translate each requirement into specific platform controls, for example single sign-on with multi-factor authentication, quarterly access reviews, encrypted storage and an annual failover test, and record which control satisfies which requirement. Evidence is proof that each control operated over a period: configuration exports, access review sign-offs, test results and log extracts, collected with timestamps and stored safely.

Auditors and supervisors working with frameworks and rules such as ISO/IEC 27001, SOC 2, BCBS 239 and DORA usually ask for evidence across a period, not a statement that a control exists. Collecting screenshots by hand each audit cycle is slow and error-prone. Mapping requirements once and collecting evidence automatically from system telemetry, audit logs and infrastructure as code makes audits faster and exposes control failures between audits. One control often satisfies several frameworks. Governance metrics differ: they measure how widely good practice is applied, not whether specific obligations were met.

# Key considerations

- Build one control library mapped to several frameworks, so a single control and its evidence serve them all.
- Prefer evidence generated by systems, such as configuration state and logs, over screenshots and attestations, and keep it in tamper-evident storage.
- A platform vendor's attestation covers the vendor's share of the controls. Map the shared-responsibility split explicitly and evidence your own part.
- Monitor key controls continuously and alert on failures, rather than discovering them at audit time.

# Questions to ask

- Which frameworks and regulations is the platform audited or supervised against?
- How is evidence collected today, and how long does audit preparation take?
- Which controls does the vendor's attestation cover, and which remain yours?
- How quickly would you know if a key control, such as multi-factor authentication or encryption, stopped working?
