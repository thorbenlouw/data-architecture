# Metadata and discovery

* [Metadata and discovery](metadata.md) - Capture, organise and expose information about data so people and machines can find, understand and trust it.
  * [Active metadata](active-metadata.md) - Use metadata to trigger actions automatically, such as propagating tags, alerting owners or blocking bad data.
  * [AI context layer](ai-context-layer.md) - Curate and serve business definitions, verified queries, relationships and usage guidance to AI agents so they interpret and use data correctly.
  * [Data catalogue](data-catalogue.md) - Provide a searchable inventory of data assets with descriptions, owners, quality and usage.
    * [AI-generated documentation](ai-generated-documentation.md) - Draft descriptions, tags and documentation for data assets using AI, for people to review.
    * [Business glossary](business-glossary.md) - Define business terms and link them to the data that represents them.
    * [Data certification](data-certification.md) - Mark assets as trusted, deprecated or under review so consumers know what to rely on.
    * [Data trust indicators](data-trust-indicators.md) - Show consumers, where they use data, whether a dataset, dashboard or answer is certified, fresh, passing its checks and free of open incidents.
    * [Event and API catalogue](event-api-catalogue.md) - List the event streams and data APIs that systems publish, with owners, schemas, versions and consumers, so teams can find, subscribe to and safely change them.
    * [Metadata harvesting](metadata-harvesting.md) - Collect technical metadata automatically from databases, pipelines, BI tools and files.
    * [Usage and popularity metadata](usage-metadata.md) - Show who uses which data, how often and how, to guide discovery and clean-up.
  * [Data lineage](data-lineage.md) - Track where data comes from, how it is transformed and where it goes.
    * [Column-level lineage](column-lineage.md) - Track how each column is derived from source columns.
    * [Document and unstructured lineage](unstructured-lineage.md) - Track which documents and chunks fed indexes, models and AI-generated answers.
    * [End-to-end lineage](cross-system-lineage.md) - Stitch lineage across ingestion tools, platforms and BI tools into one connected view.
    * [Impact analysis](impact-analysis.md) - Use lineage to find everything affected by a proposed change or a data incident.
    * [Model lineage](model-lineage.md) - Track the data, features, code and runs behind each model and its predictions.
    * [Table-level lineage](table-lineage.md) - Track dependencies between datasets, tables and views.
  * [Metadata interoperability](metadata-interoperability.md) - Exchange metadata between tools through open APIs and standards.
  * [Schema registry](schema-registry.md) - Store and version schemas for events and messages, and enforce compatibility between producers and consumers.
