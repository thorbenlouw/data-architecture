# Orchestration

* [Orchestration](orchestration.md) - Schedule, sequence and coordinate the jobs that move and transform data.
  * [Backfill and reprocessing](backfill-replay.md) - Rerun pipelines over historical periods or replay events to correct or rebuild data.
  * [Data-aware orchestration](asset-based-orchestration.md) - Schedule work based on the freshness and dependencies of data assets rather than fixed times.
  * [Event-driven triggering](event-driven-triggering.md) - Start pipelines when something happens, such as a file arriving, a table changing or a message being published.
  * [Workflow orchestration](workflow-orchestration.md) - Define pipelines as dependency graphs of tasks and run them on schedules with retries and alerts.
