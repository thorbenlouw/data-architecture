# Master and reference data

* [Master and reference data](master-data.md) - Create and maintain consistent, trusted versions of core business entities and shared code lists.
  * [Master data management](master-data-management.md) - Create a single trusted record for entities such as customer, product or supplier from many sources.
    * [Entity resolution](entity-resolution.md) - Find and link records that refer to the same real-world entity, even when they do not match exactly.
    * [Hierarchy management](hierarchy-management.md) - Maintain hierarchies and relationships such as corporate structures, product taxonomies and organisation charts.
    * [Merge and survivorship](survivorship.md) - Combine matched records into a golden record using rules about which source wins for each attribute.
  * [Product information management](product-information-management.md) - Manage product attributes, digital assets and channel-specific content, and publish them to sales channels.
  * [Reference data management](reference-data-management.md) - Manage shared code lists and mappings, such as country codes and product categories, with versions and approvals.
