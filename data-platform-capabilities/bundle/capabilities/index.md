# Capability domains

* [Ingestion and integration](ingestion-integration/) - Bring data from source systems into the platform and keep it in step with them.
* [Storage and table management](storage/) - Store data durably and cheaply in formats that many tools can read and manage it as reliable tables.
* [Processing and transformation](processing/) - Transform, clean, join and aggregate data into forms ready for use.
* [Orchestration](orchestration/) - Schedule, sequence and coordinate the jobs that move and transform data.
* [Query and compute](compute/) - Provide the query engines and processing power that run workloads, sized and isolated appropriately.
* [Serving and activation](serving/) - Deliver data to the applications, people and processes that use it, at the latency and volume they need.
* [Analytics and BI](analytics-bi/) - Help people explore, visualise and report on data to make decisions.
* [Machine learning development](machine-learning/) - Develop, train and evaluate machine learning models on platform data.
* [ML operations](mlops/) - Deploy, run, monitor and improve models in production reliably.
* [Generative AI](generative-ai/) - Build applications that use large language models and other generative models with enterprise data.
* [Metadata and discovery](metadata/) - Capture, organise and expose information about data so people and machines can find, understand and trust it.
* [Data quality and observability](data-quality/) - Measure, monitor and improve whether data is fit for its intended use.
* [Master and reference data](master-data/) - Create and maintain consistent, trusted versions of core business entities and shared code lists.
* [Governance and compliance](governance/) - Set and enforce the rules, roles and controls for how data is managed and used.
* [Security and access](security/) - Protect data from unauthorised access, loss and misuse.
* [Data sharing and collaboration](data-sharing/) - Share data within and beyond the organisation safely, without unnecessary copies.
* [Data products](data-products/) - Manage data as products with owners, consumers, contracts and service levels.
* [Development and DataOps](development-lifecycle/) - Build, test and release data and AI workloads safely and repeatably, from first commit to production.
* [Platform operations](platform-operations/) - Run the data platform itself, including provisioning, tenancy, cost, monitoring and resilience.
* [Specialised data types](specialised-data/) - Store and analyse data types that need specialised models, functions or engines.
