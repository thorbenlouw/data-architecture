# Specialised data types

* [Specialised data types](specialised-data.md) - Store and analyse data types that need specialised models, functions or engines.
  * [Bitemporal data](temporal-data.md) - Store and query data as it was true in the real world and as it was recorded in the system.
  * [Full-text search](full-text-search.md) - Index text for full-text search, relevance ranking and fast filtering.
  * [Geospatial data](geospatial-data.md) - Store, index and analyse location and shape data with spatial types and functions.
  * [Graph data](graph-data.md) - Model and query connected data as nodes and relationships.
    * [Knowledge graphs](knowledge-graphs.md) - Represent entities and their meaning in a graph with an ontology, for integration, search and grounding AI.
  * [Observability data analytics](observability-analytics.md) - Store and analyse logs, metrics and traces from applications and infrastructure at scale, with search, dashboards and alerts.
  * [Time-series data](time-series-data.md) - Store and query time-stamped measurements efficiently, with time-based functions and retention.
  * [Unstructured data management](unstructured-data.md) - Store, catalogue, govern and process documents, images, audio and video alongside structured data.
    * [Audio and video processing](audio-video-processing.md) - Transcribe and extract content from audio and video at scale for analysis and retrieval.
