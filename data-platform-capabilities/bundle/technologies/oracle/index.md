# Oracle

# Ingestion and integration

* [OCI Streaming with Apache Kafka](oracle-oci-streaming-kafka.md) - Managed Apache Kafka clusters in an OCI tenancy, with SASL/SCRAM or mTLS authentication and Kafka ACLs.
* [Oracle Fusion Data Intelligence](oracle-fusion-data-intelligence.md) - Packaged analytics for Oracle Fusion ERP, HCM, SCM and CX applications, with managed pipelines, a prebuilt data model in Autonomous AI Database and Oracle Analytics Cloud content.
* [Oracle GoldenGate](oracle-goldengate.md) - Log-based change data capture and replication between databases, and from databases to Kafka, cloud warehouses and Iceberg tables, available as software and as the managed OCI GoldenGate.

# Processing and transformation

* [OCI Data Flow](oracle-oci-data-flow.md) - Serverless Apache Spark service on OCI that runs batch and streaming Spark applications without cluster management.
* [OCI Data Integration](oracle-oci-data-integration.md) - Serverless, visual ETL and ELT service on OCI for designing data flows, pipelines and schedules, with tasks that can run on OCI Data Flow Spark.
* [Oracle AI Data Platform](oracle-ai-data-platform.md) - OCI lakehouse workbench that combines Spark compute, notebooks, workflow orchestration, a Master Catalog over Delta Lake and Iceberg data, Delta Sharing and agent building.

# Query and compute

* [MySQL HeatWave](oracle-mysql-heatwave.md) - Managed MySQL service with an in-memory, scale-out query accelerator for analytics on transactional data, and HeatWave Lakehouse for querying files in object storage.
* [Oracle AI Database 26ai](oracle-ai-database-26ai.md) - Oracle's converged database release that supports relational, JSON, graph, spatial, text and vector data in one engine for transactional and analytical work.
* [Oracle Autonomous AI Database](oracle-autonomous-ai-database.md) - Self-managing Oracle database service on OCI and other clouds that automates provisioning, patching, tuning, scaling and backups, offered as Lakehouse, Transaction Processing, JSON Database and APEX workload types.
* [Oracle Autonomous AI Lakehouse](oracle-autonomous-ai-lakehouse.md) - The analytics workload type of Autonomous AI Database, which runs Oracle SQL over its own tables and over Apache Iceberg tables in object storage registered in external catalogues.
* [Oracle Exadata](oracle-exadata.md) - Engineered database platform with scale-out storage servers that offload SQL filtering and caching, available on premises, as Exadata Database Service on OCI and as Exadata Cloud@Customer.

# Analytics and BI

* [Oracle Analytics Cloud](oracle-analytics-cloud.md) - Oracle's BI service for self-service visual analysis, governed dashboards, a semantic model, pixel-perfect reports and data preparation.
* [Oracle Analytics Cloud AI Assistant, AI Data Agents and MCP Server](oracle-analytics-cloud-ai.md) - Generative AI features in Oracle Analytics Cloud for asking questions of data in natural language, building dataset-specific agents and exposing governed analytics to external AI clients through MCP.
* [Oracle Select AI](oracle-select-ai.md) - Autonomous AI Database feature that turns natural-language prompts into SQL, answers questions with retrieval over vector stores, and generates synthetic data, using configured LLM providers.

# Machine learning development

* [MySQL HeatWave AutoML and HeatWave GenAI](oracle-heatwave-automl-genai.md) - In-database machine learning and generative AI routines in MySQL HeatWave, covering model training and scoring, embeddings, a vector store, RAG and natural-language to SQL.

# Generative AI

* [OCI Generative AI (OCI Enterprise AI)](oracle-oci-generative-ai.md) - Managed access to hosted and imported foundation models on OCI, with dedicated AI clusters, OpenAI-compatible APIs, guardrails, vector stores and a Responses API for building agents.
* [Oracle AI Database Private Agent Factory](oracle-ai-private-agent-factory.md) - No-code builder and runtime for AI agents that runs as a container in the customer's chosen environment, working against Oracle AI Database data.
* [Oracle AI Vector Search](oracle-ai-vector-search.md) - Native VECTOR data type, vector indexes and similarity functions in Oracle AI Database, combinable with relational, text, JSON, graph and spatial predicates in one SQL query.
* [Oracle Select AI Agent and Autonomous AI Database MCP Server](oracle-select-ai-agent.md) - In-database framework for defining agents, tasks and PL/SQL tools, with an Oracle-hosted MCP server that exposes those tools to external AI clients under database authorisation.

# Metadata and discovery

* [OCI Data Catalog](oracle-oci-data-catalog.md) - Managed metadata service that harvests technical metadata from OCI and on-premises sources, adds business glossary terms and tags, and provides a Hive-compatible metastore.
* [Oracle Autonomous AI Database Catalog](oracle-autonomous-ai-database-catalog.md) - A "catalogue of catalogues" in Autonomous AI Database that brings metadata from external catalogues, clouds and on-premises sources into one searchable view for discovery and access.

# Security and access

* [Oracle Data Safe](oracle-data-safe.md) - Security service for Oracle databases that assesses configuration and users, discovers and masks sensitive data, collects audit records and manages SQL Firewall.
* [Oracle Database security features](oracle-database-security.md) - Built-in controls in Oracle AI Database for row-level policies, query-time masking, separation of duties and encryption of data at rest with managed keys.

# Development and DataOps

* [OCI Data Science](oracle-oci-data-science.md) - Managed ML platform on OCI with JupyterLab notebook sessions, jobs, pipelines, a model catalogue, model deployment endpoints and AI Quick Actions for fine-tuning and evaluating foundation models.

# Platform operations

* [Oracle Database@AWS, Oracle Database@Azure and Oracle Database@Google Cloud](oracle-database-multicloud.md) - Oracle-operated Exadata and Autonomous AI Database services running inside hyperscaler data centres and bought through the hyperscaler.
