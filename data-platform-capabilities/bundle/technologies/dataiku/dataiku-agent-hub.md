Released with version 14.2 as a plugin that administrators install, and run as a visual webapp. Dataiku states that it will ultimately replace the earlier Dataiku Answers and Agent Connect chat interfaces, without giving a date. It can forward the end user's identity to agents and tools for document-level security and dataset access. Separately from Agent Hub, Dataiku agents can be reached from Slack and Microsoft Teams.
