# SAP

# Ingestion and integration

* [SAP Datasphere replication flows](sap-datasphere-replication-flows.md) - Datasphere feature that copies tables and CDS views from SAP and other sources in initial and delta mode into Datasphere or into external targets such as object stores, Kafka and cloud warehouses.
* [SAP Integration Suite](sap-integration-suite.md) - SAP BTP integration platform for process integration, API management, B2B and EDI exchange and event brokering between SAP and third-party applications.
* [SAP Landscape Transformation Replication Server](sap-landscape-transformation.md) - Trigger-based replication server that captures changes from SAP ABAP systems and other databases and applies them in near real time to HANA or other targets.

# Storage and table management

* [SAP HANA Cloud, data lake](sap-hana-cloud-data-lake.md) - Low-cost storage tier of SAP HANA Cloud with data lake Files for object storage and a data lake Relational Engine for SQL over large, colder datasets.

# Processing and transformation

* [SAP Business Warehouse in SAP Business Data Cloud](sap-business-warehouse-bdc.md) - Hosted SAP BW in BDC whose Data Product Generator turns BW InfoProvider data into data products in the BDC object store for Datasphere and Databricks to use.
* [SAP BW/4HANA](sap-bw4hana.md) - SAP's on-premises data warehouse application on SAP HANA, with modelled InfoProviders, extractors for SAP sources and query design for BI.
* [SAP Databricks](sap-databricks.md) (distribution of Databricks) - SAP-sold and SAP-managed Databricks workspace embedded in BDC, for notebooks, Spark pipelines, serverless SQL and ML over SAP data products shared with Delta Sharing.
* [SAP Datasphere](sap-datasphere.md) - SAP's cloud data warehouse and data fabric service for integrating, modelling, federating and governing SAP and non-SAP data in isolated spaces with business semantics.

# Orchestration

* [SAP Data Intelligence Cloud](sap-data-intelligence-cloud.md) (deprecated) - SAP's earlier pipeline, orchestration and metadata service for integrating SAP and non-SAP data and running ML pipelines.

# Query and compute

* [Dremio Cloud](dremio-cloud.md) - Managed lakehouse query service built on Apache Iceberg, with an Iceberg catalogue, automatic query acceleration and an AI semantic layer.
* [SAP Business Data Cloud Connect](sap-bdc-connect.md) - Bidirectional, zero-copy sharing of data and metadata between BDC and a customer's existing Databricks, Google BigQuery or Snowflake environment.
* [SAP Snowflake](sap-snowflake.md) (unconfirmed; distribution of Snowflake) - SAP-sold and SAP-operated Snowflake offering added to BDC as a solution extension, sharing SAP data products with Snowflake in both directions without copying.

# Serving and activation

* [SAP HANA Cloud](sap-hana-cloud.md) - Managed in-memory, multi-model database on SAP BTP for transactional and analytical work across relational, document, spatial, graph, time-series and vector data.

# Analytics and BI

* [SAP Analytics Cloud](sap-analytics-cloud.md) - SaaS service that combines BI stories and dashboards, enterprise planning and predictive analysis, with live connections to SAP sources and Joule for natural-language questions.

# Generative AI

* [SAP AI Agent Hub](sap-ai-agent-hub.md) - Capability of SAP LeanIX that discovers SAP and non-SAP AI agents and MCP servers, maps them to applications and processes, and tracks which are approved for use.
* [SAP AI Foundation (SAP AI Core and generative AI hub)](sap-ai-foundation.md) - SAP BTP services for running custom AI, with the generative AI hub giving governed access to many LLMs plus orchestration, grounding, content filtering and data masking.
* [SAP HANA Cloud vector engine](sap-hana-cloud-vector-engine.md) - Vector data type, similarity functions and indexes in SAP HANA Cloud for semantic search and retrieval next to business data.
* [SAP Joule and Joule agents](sap-joule.md) - SAP's AI assistant across its applications, with agents (marketed in 2026 as Joule Assistants) that carry out multi-step business tasks under the user's authorisations.
* [SAP Joule Studio](sap-joule-studio.md) - Capability in SAP Build for building Joule skills and custom agents, from no-code to pro-code, with model choice, tool access and connection to MCP servers.

# Metadata and discovery

* [SAP Datasphere catalog and Data Marketplace](sap-datasphere-catalog.md) - Catalogue for discovering and describing assets across Datasphere and connected systems, with glossary terms and KPIs, plus a marketplace for publishing and subscribing to data products.

# Master and reference data

* [SAP Master Data Governance](sap-master-data-governance.md) - Application for central creation, consolidation and governed maintenance of master data with workflows, validation rules and quality monitoring, on S/4HANA or as a cloud edition on BTP.

# Data sharing and collaboration

* [SAP Business Data Cloud](sap-business-data-cloud.md) - Managed SaaS data platform that unifies SAP application data as governed data products on a shared object store and exposes it to Datasphere, SAP Analytics Cloud, SAP Databricks and SAP Snowflake without copying.

# Data products

* [SAP Business Data Cloud data product studio](sap-bdc-data-product-studio.md) (unconfirmed) - Tooling in BDC for creating, modelling and managing customer-defined data products with SQL or visual transformations, schema, lineage, versioning and lifecycle states.
* [SAP Business Data Cloud data products](sap-bdc-data-products.md) - SAP-managed, curated datasets with business metadata for core processes in SAP Cloud ERP, SuccessFactors and other applications, populated automatically from the source systems.

# Specialised data types

* [SAP HANA Cloud knowledge graph engine](sap-hana-cloud-knowledge-graph-engine.md) - RDF triple store with SPARQL in SAP HANA Cloud, which can generate graphs automatically from database metadata for semantic search and agent grounding.
* [SAP Knowledge Graph](sap-knowledge-graph.md) - SAP-managed graph of business entities, fields and relationships across SAP applications that gives Joule and custom agents business context.
