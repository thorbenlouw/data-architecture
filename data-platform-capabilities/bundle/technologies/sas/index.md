# SAS

# Ingestion and integration

* [SAS Data Hub](sas-data-hub.md) - Data connectivity application in SAS Viya for defining and monitoring connections to databases, cloud data platforms and file stores, and for browsing and previewing their data.

# Processing and transformation

* [SAS 9.4 and SAS Enterprise Guide](sas-9.md) - Earlier SAS platform of Base SAS, SAS/STAT and other products running on Windows and Linux servers, with the SAS Enterprise Guide desktop client for code and point-and-click tasks.
* [SAS Cloud Analytic Services (CAS)](sas-cloud-analytic-services.md) - In-memory engine in SAS Viya that loads tables across a cluster of workers and runs data preparation, SQL, statistics and machine learning on them in parallel.
* [SAS Compute Server](sas-compute-server.md) - Single-machine server in SAS Viya that runs traditional SAS programs, such as DATA step and procedures, and Python code in sessions started for each user or job.
* [SAS Data and AI Studio](sas-data-and-ai-studio.md) - Browser-based development environment in SAS Viya for writing SAS and Python code and building visual flows that extract, transform and load data and run analytics.
* [SAS Event Stream Processing](sas-event-stream-processing.md) - Streaming engine that filters, aggregates, joins and scores events in continuous queries, running from edge devices to Kubernetes clusters, with a low-code designer.
* [SAS Visual Text Analytics](sas-visual-text-analytics.md) - Natural language processing application in SAS Viya that parses text, discovers topics, classifies documents, analyses sentiment and extracts information with linguistic rules, machine learning and LLMs.

# Query and compute

* [SAS Managed Cloud Services](sas-managed-cloud-services.md) - SAS-operated hosting and management of SAS software on Microsoft Azure or AWS, or in a customer's own cloud, including SAS Viya Essentials, a fixed-price set of SAS Viya products on Azure.
* [SAS SpeedyStore](sas-speedystore.md) - SingleStore database embedded in SAS Viya, so that transactional and analytical workloads and SAS analytics run against one copy of the data.
* [SAS Workload Management](sas-workload-management.md) - Scheduler for SAS Viya compute sessions and jobs on Kubernetes that routes work through rule-based queues and priorities, balances it across nodes by capacity and restarts pre-empted jobs.

# Serving and activation

* [SAS Intelligent Decisioning](sas-intelligent-decisioning.md) - Application in SAS Viya for building decision flows that combine business rules, model scores, code and calls to external APIs such as LLMs, then testing them and publishing them as batch, API or real-time services.

# Analytics and BI

* [SAS Visual Analytics](sas-visual-analytics.md) - Web application in SAS Viya for building interactive reports and dashboards, exploring data, and running automated explanations, forecasts and scenario analysis without code.

# Machine learning development

* [SAS Model Manager](sas-model-manager.md) - Model lifecycle application in SAS Viya that registers and versions SAS, Python and R models, documents them with model cards, publishes them to run-time destinations and monitors their performance and drift.
* [SAS Model Studio](sas-model-studio.md) - Browser-based machine learning application in SAS Viya that builds, compares and explains pipelines of data preparation, feature engineering and models, with automated pipeline generation and tuning.
* [SAS Visual Forecasting](sas-visual-forecasting.md) - Forecasting application in SAS Viya that builds pipelines of time series, machine learning and hybrid models for each level of a hierarchy, selects the best model for each series and reconciles forecasts across levels.

# ML operations

* [SAS Container Runtime](sas-container-runtime.md) - Packaging of SAS and Python models and decisions as lightweight OCI containers with a REST scoring endpoint that run on any container platform without a SAS Viya deployment.
* [SAS Data Accelerator](sas-data-accelerator.md) - Capability of SAS Viya that runs SAS model scoring, data quality functions and some analytics inside external databases and cloud data platforms instead of moving the data to SAS.

# Generative AI

* [SAS Agentic AI Accelerator](sas-agentic-ai-accelerator.md) - Open-source kit of code, deployment recipes and interfaces for building, governing and deploying AI agents on SAS Viya, including a no-code prompt engineering interface and recipes for hosting LLMs and embedding models.
* [SAS Retrieval Agent Manager](sas-retrieval-agent-manager.md) - No-code retrieval-augmented generation product that ingests documents, tests and selects retrieval configurations, and serves cited answers through an API, chatbot or retrieval agents.
* [SAS Viya MCP Server](sas-viya-mcp-server.md) - Self-hosted Model Context Protocol server that lets external AI agents and coding assistants run SAS code, train AutoML projects, score models and work with SAS Viya content as tools, under the user's Viya permissions.

# Metadata and discovery

* [SAS Data Governance](sas-data-governance.md) - Catalogue and governance product in SAS Viya that discovers and profiles data assets, detects personal data, records lineage from data to reports and models, and holds a business glossary.

# Data quality and observability

* [SAS Data Engineering](sas-data-engineering.md) - Packaged SAS Viya offering for building data pipelines that bundles visual and code-based development, data connectivity, data profiling, data quality, entity resolution and governance.

# Governance and compliance

* [SAS AI Navigator](sas-ai-navigator.md) - SaaS application that keeps an inventory of an organisation's AI models, agents and use cases, from SAS or elsewhere, and checks them against internal policies and imported regulatory policy packs.

# Security and access

* [SAS Viya security controls](sas-viya-security.md) - Authentication through SAS Logon with OpenID Connect, SAML or LDAP, rule-based permissions on folders, reports and services, row-level permissions on CAS tables, and audit records of user activity.

# Development and DataOps

* [SAS Data Maker](sas-data-maker.md) - Low-code application that generates synthetic tables, including related tables and time series, which keep the statistical patterns of real data, and reports the quality and privacy of the result.
* [SAS Viya Copilot](sas-viya-copilot.md) - Family of AI assistants embedded in SAS Viya applications that generate and explain SAS and Python code, guide model pipeline building and help manage models and decisions from natural-language requests.
* [SAS Viya Workbench](sas-viya-workbench.md) - Self-service cloud development environment in which data scientists code in SAS, Python or R through Jupyter, Visual Studio Code or SAS Enterprise Guide on CPU or GPU compute that scales and stops on demand.

# Platform operations

* [SAS Viya](sas-viya.md) - Cloud-native analytics and AI platform on Kubernetes that hosts SAS's data management, visual analytics, machine learning, model management, decisioning and streaming products.
